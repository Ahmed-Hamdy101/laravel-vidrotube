# MVP Scope

## Creator can

- A creator can register and sign in
- A creator can create one channel
- A creator can upload a video file and give it a title and description
- A creator can mark a video public, unlisted, or private
- A creator can see how many views a video has These five lines are a starting draft



## Viewer can

- A viewer can browse public channels and videos
- A viewer can play a public video and choose a playback quality Same rule
- A creator can upload a video file and give it a title and description
- A creator can mark a video public, unlisted, or private
- A creator can see how many views a video has These five lines are a starting draft

## Admin

- An admin can manage users and content
- An admin can remove inappropriate content
- An admin can ban users who violate terms of service
- An admin can view analytics and reports on platform usage
- An admin can manage platform settings and configurations
- An admin can moderate comments and user interactions
- An admin can handle user support and inquiries
- An admin can enforce community guidelines and policies
- An admin can manage monetization and advertising options
- An admin can generate and export reports on platform performance and user engagement
- An admin can manage partnerships and collaborations with content creators and brands
- An admin can oversee platform security and data privacy measures
- An admin can implement and update platform features and functionalities
- An admin can monitor and respond to user feedback and suggestions
- An admin can manage and update the platform's terms of service and privacy policy
