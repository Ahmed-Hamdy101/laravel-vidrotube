# Out of Scope for V1

This document lists features that are explicitly not included in the first version of Vidrotube. These items are intentionally deferred so the MVP can stay focused on the core creator/viewer workflow.

## Explicitly out of scope

- Live streaming / live events
- Monetization and ad revenue
- DRM / digital rights management
- Comments and threaded discussions
- Likes, dislikes, and social reactions
- Subscriptions, memberships, and creator tiers
- Channel recommendations / recommendation engine
- Search ranking and advanced discovery systems
- Playlists and watch later features
- Notifications and real-time messaging
- Analytics dashboards beyond basic view counts
- Multi-language localization
- Advanced moderation workflows and automated content review
- Third-party integrations and API marketplace features
- Mobile apps (iOS/Android) for V1
- Background video transcoding pipelines and complex encoding orchestration
- Enterprise admin tooling and large-scale governance features

## Design intent

The V1 product is limited to the core video publishing and playback flow:

- creator account setup
- channel creation
- video upload
- basic visibility controls (public / unlisted / private)
- public video playback
- basic statistics such as view counts

Anything beyond this is considered future work and should not be treated as required for launch.
